## Описание проекта
ZarinPay — это современная веб-приложение для управления финансами с красивым интерфейсом в стиле dark mode, стеклянными карточками и золотыми акцентами. Проект включает в себя:
- Управление банковскими счетами (текущие, сберегательные)
- Переводы между счетами и пользователями
- Кредиты (расчет, заявки, погашение)
- Депозиты и сберегательные счета
- Бюджетирование
- Финансовые цели
- ИИ-ассистент для помощи в финансовых вопросах
- Поддержка (тикеты)
- Безопасную авторизацию (подтверждение почты, история входов)
- Историю транзакций и уведомления
- Финансовый рейтинг пользователей (бронза/серебро/золото/платина)

## Установка и запуск

### Требования
- Python 3.10+
- Pip

### Шаги установки
1. Перейдите в директорию проекта:
   ```bash
   cd "c:\Users\User\Desktop\Softclub\Python Courses\Python 3\Exams\Exam 3"
   ```

2. Создайте файл .env (если нет):
   ```bash
   # Скопируйте или создайте файл .env и заполните переменные
   # SECRET_KEY=
   # DEBUG=True
   # EMAIL_HOST=
   # EMAIL_PORT=
   # EMAIL_USE_TLS=True
   # EMAIL_HOST_USER=
   # EMAIL_HOST_PASSWORD=
   # CLAUDE_API_KEY=
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Примените миграции:
   ```bash
   py manage.py migrate
   ```

5. Создайте суперпользователя (для панели администратора):
   ```bash
   py manage.py createsuperuser
   ```

6. Запустите сервер разработки:
   ```bash
   py manage.py runserver
   ```

7. Перейдите в браузере на http://127.0.0.1:8000/

## Финансовый рейтинг
В ZarinPay есть система финансового рейтинга пользователей, который рассчитывается по нескольким критериям:

### Уровни рейтинга
| Уровень | Баллы | Цвет |
|---------|-------|------|
| Бронза | 0-25 | #CD7F32 |
| Серебро | 26-50 | #C0C0C0 |
| Золото | 51-75 | #FFD700 |
| Платина | 76-100 | #E5E4E2 |

### Критерии расчета
1. **Регулярные пополнения счета (+20 баллов)**: Нужно ≥2 депозитных транзакций за последние 3 месяца
2. **Нет просроченных кредитов (+25 баллов)**: Ни одного просроченного платежа по кредиту
3. **Активный сберегательный счет (+20 баллов)**: Открытый и неудаленный сберегательный счет
4. **Использует бюджет и цели (+15 баллов)**: Создал хотя бы один бюджет и одну финансовую цель
5. **Давно зарегистрирован (+20 баллов)**: Регистрация более 3 месяцев назад

### Автоматическое обновление
- Рейтинг автоматически пересчитывается при каждом посещении профиля пользователя
- Рейтинг сохраняется в базе данных с указанием времени расчета
- Пользователь видит актуальный рейтинг и советы по его улучшению
